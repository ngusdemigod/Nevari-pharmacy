Inline Editing / Editable Fields

Instead of opening a new card or modal:

Make the price and category name directly editable on the page.

Use input fields that look like text until clicked. Example:

Pharmaceuticals → click → becomes <input value="Pharmaceuticals">
₦6,000 / min → click → <input value="6000">

On blur or enter, automatically save or show a subtle “saved” confirmation.
Add a small “pencil” icon to indicate editable fields, no extra button needed.

Benefits:

No extra modal or editor card
Minimal clicks, low cognitive load
Users see context and changes immediately
